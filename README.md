# rubble
Rubble runs three-avbd's GPU rigid-body demo scenes (AVBD, SIGGRAPH 2025) live in the Blender 5.2 viewport. The physics runs unchanged in a Node 24 + Dawn sidecar process, and Blender draws the poses it sends back. It is viewport-only: no Cycles or EEVEE render, no bake, no cache output. Windows only.
