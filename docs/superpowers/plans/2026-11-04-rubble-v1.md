# Rubble v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run ten of three-avbd's demo scenes live in the Blender 5.2 viewport. The physics comes from an unchanged
three-avbd running in a Node 24 + Dawn sidecar, and the poses are drawn by an instanced gpu-module draw handler.

**Architecture:** A Node sidecar (TypeScript) owns the GPU solver and talks to the Blender addon (Python) over
stdin (JSON lines) and stdout (framed binary). The addon starts and stops the sidecar, keeps the newest pose frame
from a reader thread, and draws all bodies with one instanced batch per shape. It creates no Blender objects.

**Tech Stack:** Node 24.19 with `--experimental-transform-types`; `webgpu@0.6.1` (Dawn); `three@0.187.0` (vendored
code imports it); three-avbd vendored at afc1442; Blender 5.2.0 Python 3.13 with `gpu` and `bpy`; numpy 2.3.4;
pytest in a repo `.venv` (system Python 3.12).

**Spec:** `docs/superpowers/specs/2026-11-04-rubble-design.md`. Read it before starting any task.

## Global Constraints

- Windows 11 only. Blender `C:\Program Files\Blender Foundation\Blender 5.2\blender.exe`; Node `C:\nvm4w\nodejs\node.exe` (24.19.0).
- three-avbd vendored at commit `afc1442e64e4b36f2d49be70bf35ea0c9b85cf6c`, never edited. Keep its LICENSE and THIRD_PARTY_NOTICES.md.

- `import bpy` / `import gpu` never at module scope in pure modules (`wire.py`, `geometry.py`, `sidecar.py`), so core tests import them without Blender.

- Cannonball = demo defaults: radius 0.7 m, mass 43 kg, friction 0.5, speed 45 m/s (`main.ts:80-83, 559`).
- Speed targets (GUI, RTX 5050): scenes ≤ ~30k bodies at 60 fps; `Brick Ring (110k)` ≥ 25 fps.

## Review Focus

1. **Node missing, wrong path, or older than 24.** The panel shows a readable error and nothing crashes. Test: Task 4 `test_start_with_bad_node_path_raises_sidecar_error`.
2. **Sidecar dies mid-session** (crash, device lost, killed). The live operator stops, the panel shows the error, and Blender doesn't hang. Test: Task 4 `test_reader_reports_dead_after_process_killed`.
3. **New file, addon reload or Blender quit while live.** The sidecar process is gone and the draw handler is removed. Test: Task 7 `test_load_pre_stops_running_sidecar`.
4. **Cannonballs add bodies after load.** New bodies get static data and are drawn. Tests: Task 3 `cannonball emits STATICS before the next FRAME`; Task 6 `test_renderer_grows_on_statics`.
5. **Stray text on the sidecar's stdout** (a vendored `console.log`). It must not corrupt the stream, and a corrupted stream fails loudly instead of hanging. Tests: Task 3 `console.log does not reach stdout`; Task 2 `test_reader_rejects_bad_magic`.

## Wire protocol (pinned; both ends implement exactly this)

- Message = 16-byte little-endian header `magic b"RBL1" | type u32 | json_len u32 | bin_len u32`, then UTF-8 JSON (`json_len` bytes), then binary (`bin_len` bytes).
- Types: `1 EVENT`, `2 SCENE`, `3 STATICS`, `4 FRAME`.
  - EVENT JSON: `{"kind":"ready"}` | `{"kind":"pick","hit":{"body":int,"local":[3],"t":float}|null}` | `{"kind":"error","message":str}`. No binary.
  - SCENE JSON: `{"name":str,"bodyCount":int,"ropes":[{"links":[int...],"color":int}]}`. Binary = statics for bodies `0..bodyCount-1`.
  - STATICS JSON: `{"from":int,"count":int}`. Binary = statics for bodies `from..from+count-1`.
  - FRAME JSON: `{"step":int,"bodyCount":int,"stepMs":float,"stats":{...GpuStats3D}}`. Binary = float32 `bodyCount×8`: `px py pz 0 qx qy qz qw`.
- Static record = float32 ×8 per body: `sx sy sz shape r g b dynamic`. `shape`: 0 box, 1 sphere, 2 ringFlat, 3 ringX, 4 ringY, 5 hidden. rgb in 0–1. `dynamic` is 0 or 1. Sizes are three-avbd's `solver.bodies[i].size`, full widths. A visual shape outside this list (e.g. capsule) is sent as 0 with one stderr warning.
- Commands = one JSON object per line on stdin, field `cmd`: `load {scene, options}`, `step`, `reset`, `pick {origin, dir}`, `drag_start {body, local, target}`, `drag_move {target}`, `drag_end`, `cannonball {origin, dir}`, `quit`.
- Every `load`/`reset` is answered by SCENE. Every `step` is answered by an optional STATICS, then FRAME. Every `pick` is answered by EVENT pick. A command that fails is answered by EVENT error, and the sidecar keeps running.

### Task 4: Python sidecar process manager

**Files:**
- Create: `rubble/sidecar.py`, `tests/core/test_sidecar.py`

**Interfaces:**
- Consumes: `MessageReader`, `Message`, `MSG` (Task 2).
- Produces:
  - `class SidecarError(Exception)`.
  - `find_node(path: str) -> str`: resolve via `shutil.which`; run `node --version`; raise `SidecarError("Node not found: …")` or `SidecarError("Node 24+ required, found vX")`.
  - `class SidecarProcess`:
    - `__init__(node: str, repo_root: str, argv: list[str] | None = None)`. `argv`, when given, replaces the whole command line; it exists for tests and the fake sidecar.
    - `start()`: Popen of `argv` or `[node, "--experimental-transform-types", "--no-warnings", "sidecar/main.ts"]` with cwd=repo_root, `stdin/stdout/stderr=PIPE`, `bufsize=0`, `creationflags=CREATE_NO_WINDOW`. It waits ≤ 15 s for EVENT ready, else raises `SidecarError`.
    - `send(cmd: dict) -> None`: no-op when dead.
    - `latest_frame() -> Message | None` returns and clears the newest FRAME; older unread frames are dropped.
    - `take_scene() -> Message | None`; `take_statics() -> list[Message]`.
    - `wait_event(kind: str, timeout: float) -> dict | None`.
    - `step_in_flight: bool`: set by the caller when sending `step`, cleared by the reader when a FRAME arrives.
    - `alive: bool`; `error: str | None` holds the last EVENT error, or the reason the reader stopped.
    - `stop(timeout: float = 2.0) -> None`: send `quit`, wait, then `kill()`. Idempotent.
  - The reader thread and the stderr thread are daemon threads; stderr lines go to `print("[rubble sidecar]", line)`.
  - Module-level `_RUNNING: set[SidecarProcess]` and `stop_all()`. These hold processes, not GPU objects.
